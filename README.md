# HaremPlugins

A simple collection of public CloudStream extension repositories gathered into one place.

This repository makes it easier to access a wide range of extensions (movies, TV series, anime, live TV, regional content, and 18+ sources) by adding a single link.

---

### How to Install

1. Open **CloudStream**
2. Go to **Settings → Extensions → Add Repository**
3. Paste this link: https://raw.githubusercontent.com/HaremCaffeine/HaremPlugins/main/repo.json
4. Tap **Add**
5. Install the extensions you want from the list that appears

---

### What This Repository Provides

- Access to many popular public CloudStream extension repositories in one place
- Movies, TV series, anime, and live content from various sources
- Regional content (Hindi, English, Italian, German, Ukrainian, Indonesian, Arabic, Turkish, Brazilian, French, etc.)
- 18+ / NSFW extensions (requires enabling NSFW in CloudStream settings)

This is an **aggregator** only. It does not host any video files or create the extensions. All extensions come from their original public repositories.

---

### Important Notes

- Some extensions may stop working over time when the original websites change.
- For 18+ content, go to **Settings → Providers** and enable **NSFW**.
- Always use a trusted CloudStream build (official or well-known community versions).
- This repository is provided for convenience only. Use at your own discretion.
